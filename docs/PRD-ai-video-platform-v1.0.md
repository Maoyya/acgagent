## 一、产品定位

### 1.1 一句话描述

**用户输入一段故事梗概，AI 帮你扩展剧情、拆分镜、画角色、生成视频——把"写故事"变成"拍电影"。**

### 1.2 我们做什么

ACG Agent 是一个面向创作者的 AI 视频生产工具。用户只需要写一段故事梗概（几百字即可），平台就会自动完成：

```
用户输入故事梗概
       │
       ▼
  ① AI 扩展完整剧情 ──→ 用户查看/编辑/确认
       │
       ▼
  ② AI 生成详细分镜脚本 ──→ 用户查看/编辑/确认
       │
       ▼
  ③ AI 生成角色设计描述 ──→ 用户查看/编辑/确认
       │
       ▼
  ④ AI 绘制角色三视图 + 分镜画面 ──→ 用户查看/重新生成/确认
       │
       ▼
  ⑤ Seedance 2.0 生成视频片段 ──→ 用户预览/下载
```

每一步用户都可以查看、修改、重新生成，确认后才进入下一步。**用户始终拥有最终决定权。**

### 1.3 我们不做什么

- **不做视频编辑器**：我们生成视频片段，不提供剪辑、拼接、加字幕等功能
- **不做社交平台**：没有关注、评论、分享等社交功能
- **不做团队协作**：v1.0 面向个人使用，不支持多人同时编辑
- **不做移动端**：v1.0 只做桌面浏览器端

### 1.4 目标用户

| 用户类型 | 典型场景 | 核心诉求 |
|---------|---------|---------|
| 短视频创作者 | "有个故事想法但不会拍视频" | 快速把文字创意变成视频内容 |
| 网文/轻小说作者 | "想把我的小说片段做成动态画面" | 用视频形式展示作品，扩大影响力 |
| ACG 爱好者 | "想看看 AI 能把我的脑洞做成什么样子" | 体验 AI 创作的乐趣 |

**v1.0 定位**：个人/小团队内部工具，优先跑通核心流程，不追求高并发和商业化。

### 1.5 竞品参考

| 产品 | 核心能力 | 与我们的区别 |
|------|---------|------------|
| 小云雀（字节跳动） | 剧本一键生视频 | 我们支持分步审核和编辑，用户控制力更强 |
| 可灵 AI（快手） | 视频生成 | 我们覆盖"故事→视频"的完整管线 |
| Runway | 国际化视频工具 | 我们面向中文用户，中文理解更好 |

## 二、产品目标与衡量指标

### 2.1 产品目标

1. **跑通核心流程**：用户能从"一段文字"走到"一段视频"
2. **用户可控制**：每个环节都能预览、编辑、重新生成
3. **产出质量可接受**：生成的视频能用于社交媒体发布

### 2.2 成功指标（v1.0）

| 指标 | 目标值 | 衡量方式 |
|------|--------|---------|
| 核心流程完成率 | > 60% | 从创建项目到获得视频的用户比例 |
| 单项目耗时 | < 30 分钟 | 从输入故事到获得首个视频片段 |
| 用户满意度 | "确认"率 > 50% | 用户选择确认而非重新生成的比例 |

### 3.2 账户系统

| 功能 | 说明 |
|------|------|
| 注册 | 用户名 + 密码，邮箱选填 |
| 登录 | 用户名 + 密码 |

> v1.0 仅支持账号密码登录。微信扫码、手机验证码等后续迭代。

### 3.3 项目管理

| 功能 | 说明 | 规则 |
|------|------|------|
| 创建项目 | 填写标题 + 故事梗概 | 标题 ≤ 200 字，梗概 ≤ 5000 字 |
| 项目列表 | 展示所有项目，按更新时间倒序 | 支持分页 |
| 项目详情 | 查看项目进度和各步骤内容 | 显示步骤进度条 |
| 删除项目 | 删除不需要的项目 | 可恢复 |

### 3.4 创作工坊（核心功能）

创作工坊采用 **分步向导 + 逐步确认** 模式。每个步骤用户都可以：

- **查看** AI 生成的内容
- **编辑** 不满意的部分
- **重新生成** 整体或局部
- **确认** 后进入下一步

---

#### Step 1：剧情扩展

> **用户故事**：我写了一个故事梗概，希望 AI 帮我扩展成完整剧情，这样我就不用自己写细节了。

**输入**：用户创建项目时填写的故事梗概

**AI 生成**：
- 根据故事梗概扩展为完整剧情
- 保持原始故事的核心情节和风格
- 补充场景描写、角色互动、情感细节
- 生成的剧情文本控制在 2000-5000 字
- 实时流式展示（打字机效果，文字逐字出现）

**用户操作**：
- 查看生成结果
- 直接在文本框中编辑剧情
- 点击「重新生成」让 AI 重新创作
- 满意后点击「确认剧情，进入下一步」

---

#### Step 2：分镜生成

> **用户故事**：我希望 AI 把剧情拆分成一个个镜头画面，这样我就知道最终视频会是什么样子。

**输入**：Step 1 确认的完整剧情

**AI 生成**：将剧情拆分为多个分镜，每个分镜包含以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 场景序号 | 属于第几个场景 | 场景 1 |
| 镜头序号 | 场景内的第几个镜头 | 镜头 2 |
| 镜头描述 | 画面内容 | "中景：猫橘子在窗台上伸懒腰，阳光洒在橘色的毛上" |
| 镜头运动 | 镜头如何运动 | 推进 / 拉远 / 左摇 / 右摇 / 固定 |
| 时长 | 镜头持续时间 | 3.0 秒 |
| 对白 | 角色说的话 | "又是美好的一天！" |
| 旁白 | 画外音/叙述 | "在这个小镇上，有一段不寻常的友谊..." |

**用户操作**：
- 查看分镜列表
- 编辑任意分镜的各个字段
- 删除不需要的分镜
- 点击「重新生成分镜」全部重来
- 满意后点击「确认分镜，进入下一步」

---

#### Step 3：角色设计

> **用户故事**：我希望 AI 帮我设计故事中每个角色的外貌，这样后续生成的图片和视频才有统一的形象。

**输入**：Step 1 确认的剧情（AI 自动从中提取角色）

**AI 生成**：为每个角色生成详细的外貌描述：

| 信息 | 说明 |
|------|------|
| 角色名 | 角色的名字 |
| 外貌描述 | 面部特征、发型、体型 |
| 服装描述 | 穿着打扮 |
| 性格特征 | 影响表情和姿态 |

**用户操作**：
- 查看角色列表
- 编辑角色名称和描述
- 删除不需要的角色
- 点击「重新生成」重来
- 逐个确认角色，全部确认后进入下一步

---

#### Step 4：图片生成

> **用户故事**：我想看到角色长什么样、每个分镜画面是什么样子，这样才能判断后续视频是否符合预期。

**输入**：Step 3 确认的角色描述 + Step 2 确认的分镜描述

**AI 生成**：

| 内容 | 数量 | 说明 |
|------|------|------|
| 角色三视图 | 每个角色 1 张 | 正面/侧面/背面，确保角色形象一致 |
| 分镜场景图 | 每个分镜 1 张 | 展示该镜头的画面构图 |

> 每张图片生成约 10-30 秒。

**用户操作**：
- 查看图片网格
- 点击放大预览
- 对不满意的图片点击「重新生成」
- 全部确认后进入下一步

---

#### Step 5：视频生成

> **用户故事**：我希望能把分镜图片变成动态视频，让我的故事"活"起来。

**输入**：Step 4 确认的分镜图片 + 镜头描述文本

**AI 生成**（Seedance 2.0）：
- 将每个分镜图片转化为 3-8 秒的视频片段
- 视频时长由分镜中的「时长」字段决定
- 异步生成，用户可看到每个片段的生成进度

> 每个视频片段生成约 1-5 分钟。

**用户操作**：
- 查看视频列表和生成进度
- 播放预览已完成的片段
- 对不满意的片段点击「重新生成」
- 下载满意的视频片段
- 所有片段生成完成后，项目标记为「已完成」

---

### 3.5 素材库

> **用户故事**：我希望能集中管理所有项目中生成的图片和视频，方便后续查看和下载。

| 功能 | 说明 |
|------|------|
| 素材总览 | 展示用户所有项目中生成的图片和视频 |
| 按类型筛选 | 图片 / 视频 |
| 按项目筛选 | 查看某个项目的所有素材 |

### 4.2 创作工坊页面布局

创作工坊是用户停留时间最长的页面，采用 **顶部步骤导航 + 左右分栏** 布局：

```
┌──────────────────────────────────────────────────────────────────┐
│  ← 返回    猫和老鼠的冒险                    步骤: ① ② ③ ④ ⑤  │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│   ┌──────────────────────┐   ┌──────────────────────────────┐   │
│   │                      │   │                              │   │
│   │   内容区              │   │   预览区                      │   │
│   │                      │   │                              │   │
│   │   当前步骤的内容       │   │   选中项的放大预览             │   │
│   │   列表/卡片/文本      │   │   图片/视频/详细编辑          │   │
│   │                      │   │                              │   │
│   │                      │   │   [重新生成]  [确认，下一步 →] │   │
│   └──────────────────────┘   └──────────────────────────────┘   │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

**顶部步骤导航**：5 个圆形图标，当前步骤高亮，已完成步骤带勾，可点击回退。

**左侧内容区**：当前步骤的结构化内容（分镜列表、角色卡片等）。

**右侧预览区**：选中项的放大预览，底部是操作按钮。

### 4.3 各步骤界面

**Step 1 剧情扩展**

```
左侧：
  · 用户原始故事梗概（只读，灰色底）
  · AI 流式生成的剧情文本（打字机效果，可编辑文本框）

右侧：
  · 完整剧情预览（格式化展示）

底部按钮：[重新生成]  [确认剧情，进入分镜 →]
```

**Step 2 分镜生成**

```
左侧：
  · 分镜卡片列表（垂直排列）
    每张卡片：序号 + 镜头描述(摘要) + 时长 + 镜头运动标签
    点击展开/选中

右侧：
  · 选中分镜的详细编辑面板
    镜头描述（文本框）、镜头运动（下拉）、时长（数字输入）、对白、旁白
  · 分镜画面预览图（Step 4 完成后显示）

底部按钮：[重新生成分镜]  [确认分镜，进入角色 →]
```

**Step 3 角色设计**

```
左侧：
  · 角色卡片网格（2 列）
    每张卡片：角色名 + 外貌描述(摘要) + 三视图缩略图（Step 4 完成后显示）

右侧：
  · 选中角色的详细编辑面板
    角色名、外貌描述、服装描述、性格特征

底部按钮：[重新生成角色]  [确认角色，生成图片 →]
```

**Step 4 图片生成**

```
左侧：
  · 图片网格（3 列）
    分类 Tab：[角色三视图] [分镜场景图]
    每张图片卡片：缩略图 + 标签 + 状态（生成中/已完成/失败）

右侧：
  · 选中图片的放大预览

每张图片操作：[重新生成] [✓ 确认]
底部按钮：[全部确认，生成视频 →]
```

**Step 5 视频生成**

```
左侧：
  · 视频列表
    每项：分镜序号 + 描述(摘要) + 状态标签 + 进度条

右侧：
  · 视频播放器（点击列表项切换播放）

每项操作：[重新生成] [⬇ 下载]
底部按钮：[下载全部]
```

## 八、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| AI 生成质量不稳定 | 用户反复重新生成，体验差 | 支持局部重新生成，减少等待时间 |
| 视频生成耗时长 | 用户流失 | 显示预估时间，支持后台生成，完成后通知 |
| 角色形象不一致 | 同一角色在不同画面中长得不一样 | v1.0 先接受，v1.1 通过参考图约束改善 |
| API 调用费用高 | 成本不可控 | 设置单项目生成次数上限，监控用量 |
| 内容合规风险 | 生成不当内容 | 接入内容审核，违规内容自动拦截 |

## 九、验收标准

### 9.1 核心流程验收
