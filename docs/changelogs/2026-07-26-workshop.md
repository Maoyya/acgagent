# 2026-07-26 创作工坊 LLM 化（②剧情 / ③分镜 / ④角色 + 多项目落库）

## 变更原因
前端「创作工坊」(`acgagent-web/src/views/workshop/Index.vue`) 5 步流水线原先 ②剧情/③分镜/④角色/⑤视频全是 mock 数据，`handleGenerate` 只 `setTimeout` 假装生成。本次把 **②③④ 接真实大模型**（复用 prompt 功能的 Java→Python→LLM + SSE 基建），并新增 **多项目落库**（每用户私有 CRUD）。⑤视频生成（文生视频，非 LLM）单独立 spec，本期保持 disabled 占位。

## 影响范围
- **数据库**：新增表 `workshop_project`（acg-user/schema.sql）—— user_id/title/story/plot/storyboard(JSON)/characters(JSON)。
- **API（新增，/api/workshop）**：项目 CRUD（POST/GET-list/GET-id/PUT-id/DELETE-id `/projects`）+ 生成（`POST /plot` SSE 流式 / `POST /storyboard` / `POST /characters` 同步结构化）。
- **网关**：Nacos `acg-gateway.yaml` 的 acg-chat 路由新增 `,/api/workshop/**`。
- **公共代码**：Python(acgagent-ai) 新增 workshop api/service/builder/models；Java(acgagent) 新增 WorkshopProjectDO/Mapper + 8 VO + WorkshopService/Controller + PythonAiClient workshop 段；前端(acgagent-web) 新增 workshop types/api + Index.vue 改造（项目选择器/手动生成/落库/角色自动配色）。
- **复用**：复用刚修好的 SSE 链路（`PythonAiClient.stripSseData` + `filter("{")`），②剧情流式与 prompt generate 同款。

## 变更前后对比
- `workshop/Index.vue`：删除 4 组 mock 数据 ref + `handleGenerate` 的 setTimeout；改为项目选择器 + 每步「生成」手动触发 + 生成后 PUT 落库；角色头像由前端 `colorFromName` 自动配色（非 LLM）。
- generate/生成端点**无状态**（只返结果），落库由前端 `PUT /workshop/projects/{id}` 完成（与 prompt 的 generate→create 分离一致）。
- ②剧情：SSE 流式逐 token（content/done/error 事件）；③分镜/④角色：Python `with_structured_output` 同步结构化 JSON。

## 注意点
- **⑤视频未做**（步骤 5 在 UI 保持 disabled 占位），下一轮独立 spec（文生视频 API、异步任务/轮询/存储），依赖③分镜输出。
- **生成端点不做 moderation**（创作是纯生成，无合规闸门，区别于提示词模板）。
- **角色 color 前端自动配色**，不让 LLM 选（不可靠）。
- **部署 OPS**：① MySQL（host 3306 + Docker 3307）建 `workshop_project` 表；② Nacos 控制台 `acg-gateway.yaml` 给 acg-chat 路由追加 `,/api/workshop/**` + 重启 gateway，否则 /api/workshop 网关 404。
- **前端安全**：剧情文本（LLM 输出）用 `{{ plotText }}` 文本插值 + `white-space: pre-wrap` 渲染（**不用 v-html**，防 XSS）。
