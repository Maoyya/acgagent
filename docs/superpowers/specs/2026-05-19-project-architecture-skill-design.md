# Project Architecture Skill — 设计文档

**日期:** 2026-05-19

## 概述

在 `.claude/skills/` 下创建一个项目级 skill `project-architecture`，根据用户触发词自动扫描项目代码，生成两份文档：业务流程与技术架构。

## 触发条件

用户输入包含以下关键词时触发：
- 重新构建项目文档
- 更新项目文档
- 更改技术架构
- 重新梳理技术架构

## Skill 文件

**路径:** `.claude/skills/project-architecture.md`

独立文件，包含触发描述和完整的分析指令 + 文档模板，不依赖外部脚本。Claude Code 通过 Skill 工具加载并执行。

## 输出

### 输出目录

`docx/`（项目根目录下）

### docx/业务流程.md

| 章节 | 内容 |
|---|---|
| 1. 项目概述 | 项目名称、简介 |
| 2. 接口总览 | 按模块/Controller 列出所有接口（路径、HTTP 方法、功能说明） |
| 3. 接口详情 | 逐个接口的入参、出参、响应示例 |
| 4. Bean/实体说明 | 所有 Entity、DTO、VO 的字段及含义 |
| 5. 枚举说明 | 所有枚举类及枚举值含义 |
| 6. 工具类说明 | 公共工具类的功能描述和使用方式 |
| 7. 业务流程图 | PlantUML 时序图，展示用户→网关→服务→数据库的调用链路 |

### docx/技术架构.md

| 章节 | 内容 |
|---|---|
| 1. 技术选型 | 语言版本、框架及版本、核心依赖 |
| 2. 模块结构 | Maven 模块划分与 PlantUML 依赖关系图，各模块职责 |
| 3. 技术规范 | 代码规范、API 规范（统一响应格式、异常处理、REST 约定）、数据库规范 |
| 4. 安全限制 | 认证鉴权机制、CORS/CSRF 策略、敏感数据处理 |
| 5. 数据库设计 | 表结构（字段、类型、索引、注释）、PlantUML ER 图 |
| 6. 配置说明 | 端口、数据源、Nacos 等关键配置 |
| 7. 部署架构 | PlantUML 服务拓扑图，各服务端口与职责 |
| 8. 部署方式与命令 | 构建命令、启动命令 |

## 执行流程

1. 扫描所有模块的 `pom.xml` 获取依赖和模块关系
2. 扫描所有 `*Controller.java` 获取接口定义
3. 扫描 `src/main/resources/` 下的配置文件（application.yml、schema.sql 等）
4. 扫描所有 Entity、DTO、Enum、工具类
5. 按文档模板填充内容，首次生成时创建 `docx/` 目录
6. 生成 PlantUML 图表（模块依赖图、服务拓扑图、ER 图、业务时序图）
